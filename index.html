01
DATA

Google Sheets

사용자가 남긴 닉네임과 응원메시지를 시트의 data 탭에 차곡차곡 저장합니다.

02
API

Apps Script

웹페이지와 Google Sheets 사이를 연결하는 가벼운 API 서버 역할을 합니다.

03
WEB

HTML + AI Studio

아이디어를 실제 화면과 인터랙션으로 구현하고 GitHub Pages로 공개합니다.

Project Stack

작게 시작해서 필요한 기능을 하나씩 붙일 수 있도록 구성했습니다.

01

HTML / CSS / JS

웹페이지의 구조, 디자인, 애니메이션, 폼 입력을 담당합니다.

02

Apps Script

폼 데이터를 받아 Google Sheets에 저장하고, 저장된 메시지를 웹으로 전달합니다.

03

GitHub Pages

완성한 정적 웹페이지를 저장소와 연결해 실제 공개 페이지로 배포합니다.
